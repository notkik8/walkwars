## 🎯 Описание

WalkWars - это приложение для мотивации к активному образу жизни через соревнования в группах. Пользователи могут:
- Регистрироваться и входить в систему
- Создавать группы для соревнований
- Присоединяться к существующим группам
- Отправлять количество пройденных шагов
- Просматривать таблицу лидеров
- Переключаться между светлой и темной темой

## 🛠 Технологии

### Backend
- **FastAPI** - современный веб-фреймворк для Python
- **SQLAlchemy** - ORM для работы с базой данных
- **PostgreSQL** - реляционная база данных
- **Pydantic** - валидация данных
- **JWT** - аутентификация через токены
- **pwdlib** - хеширование паролей

### Frontend
- **React 19** - библиотека для создания пользовательских интерфейсов
- **TypeScript** - типизированный JavaScript
- **Vite** - быстрый сборщик и dev-сервер
- **React Router** - маршрутизация
- **Framer Motion** - библиотека анимаций
- **Axios** - HTTP клиент

## 🚀 Установка и запуск

### Требования

- Python 3.9+
- Node.js 18+
- PostgreSQL 12+

### Backend

1. Перейдите в директорию backend:
```bash
cd backend
```

2. Создайте виртуальное окружение:
```bash
python -m venv venv
source venv/bin/activate  # На Windows: venv\Scripts\activate
```

3. Установите зависимости:
```bash
pip install -r requirements.txt
```

4. Настройте базу данных:
   - Создайте базу данных PostgreSQL
   - Обновите `DATABASE_URL` в `app/database.py` или используйте переменные окружения

5. Запустите сервер:
```bash
uvicorn app.main:app --reload
```

Backend будет доступен по адресу: `http://localhost:8000`

### Frontend

1. Перейдите в директорию frontend:
```bash
cd frontend
```

2. Установите зависимости:
```bash
npm install
```

3. Запустите dev-сервер:
```bash
npm run dev
```

Frontend будет доступен по адресу: `http://localhost:5173`

### Сборка для production

**Backend:**
```bash
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

**Frontend:**
```bash
npm run build
npm run preview
```

## 📡 API документация

После запуска backend, документация API доступна по адресам:
- Swagger UI: `http://localhost:8000/docs`
- ReDoc: `http://localhost:8000/redoc`

### Основные endpoints

#### Аутентификация
- `POST /auth/register` - Регистрация пользователя
- `POST /auth/login` - Вход в систему

#### Группы
- `GET /groups` - Список всех групп
- `POST /groups` - Создание новой группы
- `POST /groups/{group_id}/join` - Присоединение к группе

#### Шаги
- `POST /steps/{group_id}` - Отправка количества шагов
- `GET /steps/leaderboard/{group_id}` - Таблица лидеров группы

## ✨ Особенности

### Архитектура

Проект использует **трехслойную архитектуру**:
- **Routes** → **Services** → **Repositories** → **Database**
- Разделение ответственности между слоями
- Легкое тестирование и поддержка

### Безопасность

- JWT токены для аутентификации
- Хеширование паролей с помощью pwdlib
- CORS настройки для безопасности
- Валидация данных через Pydantic

### UI/UX

- **Светлая и темная тема** с переключением
- Плавные анимации на Framer Motion
- Адаптивный дизайн для всех устройств
- Виджет погоды в реальном времени
- Минималистичный и современный интерфейс

### Функциональность

- Создание и управление группами
- Отслеживание шагов
- Таблица лидеров с агрегацией данных
- Профиль пользователя
- Валидация данных (максимум 500,000 шагов за раз)

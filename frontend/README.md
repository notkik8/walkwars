# WalkWars Frontend

Минималистичный и красивый дизайн в темных оттенках на React + Vite с множеством анимаций.

## 🚀 Быстрый старт

```bash
npm install
npm run dev
```

## 📁 Структура проекта

```
src/
├── components/          # Переиспользуемые компоненты
│   ├── Button/        # Кнопки с анимациями
│   ├── Card/          # Карточки с эффектами
│   ├── Footer/        # Футер с анимациями
│   ├── Header/        # Хедер с эффектом стекла
│   └── Layout/        # Основной layout с градиентными орбами
├── pages/             # Страницы приложения
│   └── Home/          # Главная страница
├── styles/            # Глобальные стили
│   └── globals.css    # Темная тема и переменные
├── App.tsx            # Главный компонент
└── main.tsx           # Точка входа
```

## 🎨 Особенности дизайна

- **Темная тема** с градиентными акцентами
- **Множество анимаций** на Framer Motion
- **Минималистичный дизайн** с акцентом на контент
- **Адаптивная верстка** для всех устройств
- **Плавные переходы** и эффекты наведения

## 🛠 Технологии

- React 19
- TypeScript
- Vite
- Framer Motion (анимации)
- React Router (роутинг)

## 📦 Основные компоненты

### Layout
Основной layout с анимированными градиентными орбами на фоне.

### Header
Фиксированный хедер с эффектом стекла при скролле и мобильным меню.

### Footer
Анимированный футер с социальными ссылками и колонками.

### Button
Кнопки с различными вариантами (primary, secondary, ghost) и анимациями.

### Card
Карточки с эффектами свечения и анимациями при наведении.

## 🎭 Анимации

- Fade in/out
- Slide in (left/right)
- Scale in
- Float
- Pulse
- Glow
- Rotate
- Hover effects

# Интеграция с Backend API

Все API endpoints из backend теперь имеют рабочие страницы во frontend.

## 🔐 Аутентификация

### Страницы:
- **`/login`** - Страница входа
- **`/register`** - Страница регистрации

### API Endpoints:
- `POST /auth/register` - Регистрация нового пользователя
- `POST /auth/login` - Вход в систему

## 👤 Аккаунт

### Страница:
- **`/account`** - Страница профиля пользователя (защищена)

### Функционал:
- Просмотр информации о профиле
- Быстрые действия (переход к командам, создание команды)
- Выход из аккаунта

## 👥 Команды (Groups)

### Страницы:
- **`/groups`** - Список всех команд (защищена)
- **`/groups/create`** - Создание новой команды (защищена)
- **`/groups/:id`** - Детали команды с лидербордом (защищена)

### API Endpoints:
- `GET /groups/` - Получить список всех команд
- `POST /groups/` - Создать новую команду
- `POST /groups/{group_id}/join` - Присоединиться к команде

### Функционал:
- Просмотр всех доступных команд
- Создание команды с выбором типа (публичная, приватная, соревновательная)
- Присоединение к команде
- Просмотр деталей команды

## 🚶 Шаги (Steps)

### Страница:
- **`/groups/:id`** - Отправка шагов и просмотр лидерборда

### API Endpoints:
- `POST /steps/{group_id}` - Отправить шаги
- `GET /steps/leaderboard/{group_id}` - Получить лидерборд команды

### Функционал:
- Отправка количества шагов в команду
- Просмотр лидерборда с общим количеством шагов каждого участника
- Автоматическое обновление лидерборда после отправки шагов

## 🛡️ Защищенные маршруты

Все страницы кроме `/`, `/login` и `/register` защищены и требуют аутентификации.

## 📁 Структура API

```
src/
├── api/
│   ├── client.ts          # Axios клиент с interceptors
│   ├── auth.ts            # API для аутентификации
│   ├── groups.ts          # API для команд
│   └── steps.ts           # API для шагов
├── contexts/
│   └── AuthContext.tsx    # Контекст аутентификации
└── components/
    └── ProtectedRoute/    # Компонент для защиты маршрутов
```

## 🔧 Настройка

### Backend CORS
Обновлен для работы с Vite (порт 5173):
```python
allow_origins=["http://localhost:5173", "http://localhost:3000"]
```

### API Base URL
Настроен в `src/api/client.ts`:
```typescript
const API_BASE_URL = 'http://localhost:8000';
```

## 🚀 Использование

1. Запустите backend:
```bash
cd walkwars/backend
uvicorn app.main:app --reload
```

2. Запустите frontend:
```bash
cd walkwars/frontend
npm run dev
```

3. Откройте браузер: `http://localhost:5173`
